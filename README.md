# Мото Стант — стант и эндуро на мотоциклах

Android-игра (APK собирается автоматически через GitHub Actions).

## Что есть
- Гараж: 3 мотоцикла (Дельта, Минск Кросс, Тайфун 450), тюнинг (двигатель, колёса, подвеска, рама), покраска
- Режим **Стант-парк** — 90 секунд трюков: сальто, вилли, стоппи, полёты, комбо-множитель
- Режим **Эндуро** — 5 трасс (лес, карьер, холмы, горы, ночь), чекпоинты, монеты, рекорды
- **Онлайн-гонки** на 2–4 игрока: быстрый поиск или комната по коду
- Задания с наградами, звук мотора, сохранение прогресса

## Как получить APK
1. Создай репозиторий на github.com.
2. Залей файлы проекта (папка `.github` обязательно должна попасть в репозиторий).
3. Вкладка **Actions** → сборка запустится сама (или нажми *Run workflow*).
4. Через ~3–5 минут открой завершённый запуск → внизу **Artifacts → MotoStunt-apk** → скачай, распакуй, установи APK.

## Правка кода
Код игры — `tools/engine.js` (физика, трассы) и `tools/app.js` (интерфейс, гараж).
После правки запусти `./build_html.sh` — он соберёт `app/src/main/assets/index.html`.
Игру можно тестировать прямо в браузере, открыв `index.html` (стрелки/WASD).

## iOS (IPA)
Workflow `build-ipa.yml` собирает неподписанный `MotoStunt.ipa` на macOS-сервере GitHub.
Ставится через Sideloadly / AltStore (бесплатный Apple ID, переподпись раз в 7 дней).

## Сервер мультиплеера (`server/`)
Чистый Node.js без зависимостей. На Render: Web Service, Build `npm install`, Start `node server.js`.
Имя сервиса `motostunt-server` → игра подключится сама. Иначе адрес вписывается в ⚙️ настройках игры.
Сервер также отдаёт веб-версию игры по своему адресу.
